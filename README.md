# Tutoria
### 1. Què és el més important que vas aprendre durant primer d'SMX?
 - Vaig aprendre a muntar i desmuntar ordinadors, instal·lar sistemes operatius com Windows i Ubuntu i conèixer els components d'un ordinador. També vaig aprendre conceptes bàsics de xarxes i a solucionar alguns problemes informàtics.

### 2. Quina activitat d'informàtica se't dona especialment bé?
- Se'm dona bé muntar ordinadors, identificar-ne els components i instal·lar sistemes operatius. També m'agrada fer pràctiques amb els ordinadors i buscar solucions quan hi ha algun problema.

### 3. Quina competència tècnica necessites millorar?
- Necessito millorar els meus coneixements de xarxes, sobretot la configuració d'adreces IP, els encaminadors i la resolució de problemes de connexió. També vull practicar més amb Linux i les ordres del terminal.

### 4. Què t'agradaria fer quan acabis el grau mitjà? Explica per què.
- M'agradaria continuar estudiant un grau superior d'informàtica per ampliar els meus coneixements i tenir més oportunitats laborals en el futur. També m'agradaria adquirir experiència treballant en una empresa d'informàtica.

### 5. Com t'organitzes per estudiar i fer les tasques?
- Normalment faig les activitats que em demanen a classe i intento acabar-les dins del termini. Quan alguna cosa em costa, busco informació a Internet o demano ajuda al professor. Podria millorar l'organització dedicant una estona cada setmana a repassar.
### 6. Què et motiva a continuar aprenent informàtica?
- M'agrada la informàtica perquè és un sector amb moltes sortides professionals i sempre hi ha coses noves per aprendre. Em motiva saber solucionar problemes, entendre com funcionen els ordinadors i poder treballar d'alguna cosa relacionada amb la tecnologia.
